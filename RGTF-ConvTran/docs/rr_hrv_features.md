# RR/HRV特征构建算法

## R峰检测

算法对已经加载到内存中的ECG数组执行以下步骤：

1. 将信号转换为浮点数组并执行基本维度检查；
2. 对候选信号进行z-score标准化；
3. 使用二阶Butterworth滤波器提取5–20 Hz QRS频段；
4. 尝试候选导联、信号正负极性及多个prominence阈值；
5. 设置250 ms最小峰间距；
6. 根据有效RR数量、峰值幅度、RR变异程度和中位RR进行候选评分；
7. 返回评分最高的R峰序列和检测元数据。

采样率由调用者传入，算法没有内置任何数据集的固定采样率。

## 14维特征

| 序号 | 名称 | 定义 |
|---:|---|---|
| 1 | `mean_rr` | 有效RR间期均值 |
| 2 | `std_rr` | RR间期样本标准差 |
| 3 | `rmssd` | 相邻RR差值均方根 |
| 4 | `sdsd` | 相邻RR差值样本标准差 |
| 5 | `pnn50` | 相邻RR差值大于50 ms的比例 |
| 6 | `mean_hr` | 心率均值 |
| 7 | `std_hr` | 心率样本标准差 |
| 8 | `min_rr` | 最小RR间期 |
| 9 | `max_rr` | 最大RR间期 |
| 10 | `rr_range` | RR间期极差 |
| 11 | `cvrr` | RR变异系数 |
| 12 | `median_rr` | RR间期中位数 |
| 13 | `iqr_rr` | RR间期四分位距 |
| 14 | `num_r_peaks` | 检测到的R峰数量 |

## 缺失值和标准化

当有效R峰或RR间期不足时，不可计算的特征返回`NaN`。公开API还提供：

- `fit_feature_normalizer`：从调用者提供的参考特征集合计算中位数填充值、均值和标准差；
- `transform_features`：使用调用者提供的统计量完成缺失值填充和z-score转换。

这些函数不读取文件、不选择数据划分，也不保存统计量。如何组织参考集合完全由调用者决定。
